١ — ثبّت سكربت MTK MEDIA ٢ — افتح MTK MEDIA

التثبيت على أندرويد

  1. نزّل متصفح Firefox من Google Play.
  2. من قائمة Firefox ← الإضافات، ثبّت Tampermonkey.
  3. افتح هالصفحة بـ Firefox واكبس «ثبّت سكربت MTK MEDIA» ثم Install.
  4. اكبس «افتح MTK MEDIA». أول مرة ممكن يطلب منك تحقق Cloudflare، اكبس عليه مرة وحدة.
  5. حظر إعلانات إضافي: ثبّت إضافة uBlock Origin بـ Firefox.
  6. صوت تلقائي: Firefox ← الإعدادات ← أذونات المواقع ← التشغيل التلقائي ← اختار «السماح بالصوت والفيديو».

التثبيت على آيفون

  1. نزّل تطبيق Userscripts (مجاني) من App Store.
  2. الإعدادات ← Safari ← الإضافات ← فعّل Userscripts واسمحلو بكل المواقع.
  3. افتح هالصفحة بـ Safari، اكبس «ثبّت سكربت MTK MEDIA»، بعدين من أيقونة Userscripts بشريط العنوان اكبس Install.
  4. اكبس «افتح MTK MEDIA». أول مرة ممكن يطلب تحقق Cloudflare، اكبس عليه مرة وحدة.
  5. حظر إعلانات إضافي: نزّل AdGuard وفعّلو من الإعدادات ← Safari ← الإضافات.
  6. صوت تلقائي: على موقع فاصل اكبس «ᴀA» بشريط العنوان ← إعدادات الموقع ← التشغيل التلقائي ← «السماح بالكل».
نصيحة: من قائمة المتصفح اختار «إضافة إلى الشاشة الرئيسية» على صفحة MTK MEDIA ليصير متل تطبيق.
