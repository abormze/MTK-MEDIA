# MTK-MEDIA
MTK MEDIA - mobile ad-free skin for fasel-hd (userscript + GitHub Pages `/mobile`).

- Install page: https://abormze.github.io/MTK-MEDIA/mobile/
- Userscript: `mtk-media.user.js` (Tampermonkey / Userscripts app)

The script runs on the user's own browser on fasel-hd pages: it replaces the page with the MTK MEDIA mobile UI (no site scripts/ads run), always loads watch server #01 in the player, blocks popups and strips JW Player ad config. Home is `https://www.fasel-hd.co/mobile`.
